# 📊 Валидация CSV и загрузка данных в SQLite

Данный проект представляет собой скрипт на Python для обработки внешних CSV-файлов. Программа автоматически проверяет данные на корректность, сохраняет ошибочные строки в отдельный файл, а валидные — загружает в базу данных SQLite с защитой от дублей.

## 🛠 Реализованный функционал
- Чтение данных через `csv.DictReader`.
- Проверка обязательных полей.
- Валидация ID тикетов, email-адресов, статусов и затраченных часов.
- Сбор полного списка ошибок для каждой строки.
- Экспорт невалидных строк в `rejected_tickets.csv` с указанием причины.
- Загрузка валидных данных в `service.db` (SQLite).
- Защита от повторного добавления одинаковых строк (`INSERT OR IGNORE`).
- Формирование контрольного отчета в консоли.

## 📂 Структура проекта
- `main.py` — основной скрипт (чтение, валидация, отчет).
- `db.py` — модуль для работы с базой данных (транзакции).
- `tickets_raw (3).csv` — исходный файл с данными.
- `rejected_tickets.csv` — генерируется автоматически (содержит бракованные строки).
- `service.db` — генерируется автоматически (база данных SQLite).
