# 🎓 edu_pipeline — обработка заявок онлайн-платформы «НОРД-Класс»

Консольный проект итоговой контрольной: платформа принимает заявки студентов
на курсы. Внешний оператор каждый день присылает «сырой» CSV-файл, в котором
есть и корректные строки, и ошибочные. Проект проверяет каждую строку и
объясняет каждый отказ, загружает хорошие заявки в базу данных, строит
аналитический отчёт с потенциальной выручкой, выгружает итоги двум внешним
системам (одна понимает JSON, другая — XML) и сопровождается автоматическими
тестами.

**Всё работает одной командой** — `python run_all.py` — и написано только на
стандартной библиотеке Python: никаких `pip install` для основных шагов.

🚀 Быстрый старт
1. Установить Python (если его нет)
Проще всего: Microsoft Store → найти «Python 3.13» → «Получить».

Или с python.org: в первом окне
установщика обязательно поставьте галочку «Add Python to PATH».

Проверка: откройте командную строку и выполните python --version — должно
напечататься что-то вроде Python 3.13.x.

2. Скачать проект
Через GitHub: зелёная кнопка Code → Download ZIP, распаковать.

Или через git: git clone https://github.com/sashalebedev1303-blip/Nord-class.git

3. Запустить одной командой
Откройте папку edu_pipeline и выполните:

bash
python run_all.py
💡 Как открыть командную строку сразу в нужной папке: откройте её в
Проводнике, щёлкните по пустому месту адресной строки, сотрите всё,
напечатайте cmd и нажмите Enter.

Скрипт сам удалит папку results/, выполнит все 11 шагов по порядку, в конце
покажет чек-лист созданных файлов. Дополнительных библиотек ставить не нужно.
Единственное исключение — шаг 11 (аналитический ноутбук): если Jupyter не
установлен, run_all.py сам предложит поставить его во время прогона
(ответьте Y, нужен интернет). Даже без него прогон пройдёт до конца.

❓ Частые вопросы
Можно ли запустить всё заново? Да — просто выполните python run_all.py
ещё раз: он сам удалит results/ и пересоздаст всё.

Что именно запускать? Только run_all.py одной командой. Отдельные файлы
нужны для пошаговой демонстрации этапов (например, на защите).

Пишет «python не является внутренней или внешней командой»? Python не
установлен или ставился без галочки «Add Python to PATH». Установите его и
откройте командную строку заново.

Шаг 11 пишет «Jupyter command not found»? Так бывает на Windows: pip
кладёт команды в папку, которой нет в PATH. run_all.py это обходит — он
запускает python -m nbconvert, такой вызов не зависит от PATH. Вручную:

bash
python -m nbconvert --to notebook --execute report_enrollments.ipynb --inplace
Нужен ли интернет? Только если Jupyter не установлен и вы соглашаетесь на
его авто-установку на шаге 11. Остальные шаги работают офлайн.

Почему и JSON, и XML? Две внешние системы принимают разные форматы;
содержимое одинаковое, проект сверяет его сам.

Что с ошибками в данных? Ни одна строка не выбрасывается молча: у каждой
отклонённой строки есть причина в rejected_enrollments.csv.
