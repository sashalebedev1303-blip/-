# 🎓 edu_pipeline — обработка заявок онлайн-платформы «НОРД-Класс»

![Python](https://img.shields.io/badge/Python-3.10%2B-3776AB?logo=python&logoColor=white)
![Tests](https://img.shields.io/badge/автотесты-34%20%2F%2034%20OK-success)
![Dependencies](https://img.shields.io/badge/зависимости-нет%2C%20только%20stdlib-orange)
![DB](https://img.shields.io/badge/БД-SQLite-003B57?logo=sqlite&logoColor=white)

Консольный проект итоговой контрольной: платформа принимает заявки студентов
на курсы. Внешний оператор каждый день присылает «сырой» CSV-файл, в котором
есть и корректные строки, и ошибочные. Проект проверяет каждую строку и
объясняет каждый отказ, загружает хорошие заявки в базу данных, строит
аналитический отчёт с потенциальной выручкой, выгружает итоги двум внешним
системам (одна понимает JSON, другая — XML) и сопровождается автоматическими
тестами.

**Всё работает одной командой** — `python run_all.py` — и написано только на
стандартной библиотеке Python: никаких `pip install` для основных шагов.
